# 中药系统 (Zhongyao System)

## 项目简介

中药系统是一个基于 Python+Django 开发的融合大模型的综合性中药信息平台，旨在为用户提供中药材相关的全方位服务。系统集成了中药图像识别、药材资料管理、销售、价格查询、药闻和大模型答疑等核心功能，为中药材从业者、研究者和爱好者提供便捷的信息获取和交互平台。

## 功能特性

### 1. 账号管理与个人中心
- **用户认证**：支持用户注册、登录和注销
- **个人中心**：查看和编辑个人信息，管理自己发布的供应/需求信息
- **权限管理**：区分超级用户和普通用户，超级用户可访问后台管理
- **用户资料**：支持头像上传、个人简介和联系电话管理

### 2. 中药材资料管理
- **中药材信息**：提供详细的中药材信息，包括名称、拉丁名、分类、产地、性味归经、功效、主治、用法用量等
- **方剂管理**：收录经典方剂，包括组成、用量、制法、功效、主治等信息
- **药膳食疗**：提供药膳食疗配方，包括原料、制法、功效、适用症等
- **针灸穴位**：详细的针灸穴位信息，包括定位、功效、主治、刺灸法等
- **搜索功能**：支持多条件搜索和筛选

### 3. 中药图像识别
- **图像上传**：支持上传图片进行中药材识别
- **多模型融合**：融合本地模型和百度API识别结果，提高识别准确率
- **识别结果**：提供识别置信度和候选结果
- **辅助识别**：支持基于颜色和纹理的辅助识别
- **识别历史**：记录用户的识别历史

### 4. 药材销售系统
- **供应信息**：发布和管理中药材供应信息
- **求购信息**：发布和管理中药材求购信息
- **详细信息**：支持16标签信息展示，包括规格、数量、产地、价格等
- **搜索筛选**：多条件搜索和筛选功能
- **Excel导入**：支持基于Excel数据的批量导入
- **个人管理**：在个人中心管理自己发布的信息

### 5. 价格模块
- **价格爬取**：自动爬取今日价格数据
- **价格历史**：记录价格历史数据
- **分页展示**：支持分页展示和跳转功能
- **价格说明**：提供价格单位说明
- **后台加载**：支持后台加载数据，提高页面响应速度

### 6. 药闻
- **新闻资讯**：提供中药材相关新闻和资讯
- **分类管理**：支持新闻分类
- **发布管理**：超级用户可发布和管理新闻

### 7. 大模型答疑
- **智能问答**：基于GLM-4.7-Flash的智能问答系统
- **专业解答**：支持中药材相关问题的专业解答
- **多轮对话**：支持多轮对话，提供连贯的问答体验
- **问答历史**：记录用户的问答历史

### 8. 站点管理
- **全中文界面**：包括管理后台在内的全中文界面
- **本地化**：应用和模型名称均已本地化
- **界面优化**：优化的用户界面和排版
- **响应式设计**：支持不同设备的响应式布局

## 技术栈

### 后端
- **编程语言**：Python 3.12+
- **Web框架**：Django 4.2+
- **数据库**：SQLite (本地文件数据库)
- **ORM**：Django ORM

### 前端
- **HTML5**：页面结构
- **CSS3**：样式设计
- **JavaScript**：交互逻辑
- **Bootstrap 5**：响应式布局和组件
- **Font Awesome**：图标库

### 人工智能
- **大模型**：GLM-4.7-Flash API
- **图像处理**：Pillow、TensorFlow
- **图像识别**：本地模型 + 百度API

### 数据处理
- **Excel处理**：Pandas
- **网络请求**：Requests
- **数据存储**：JSON、SQLite

## 快速开始

### 1. 环境要求
- Python 3.12 或更高版本
- pip 包管理工具
- 互联网连接（用于API调用和价格爬取）

### 2. 安装步骤

#### 2.1 克隆项目

```bash
git clone <repository-url>
cd zhongyao_system
```

#### 2.2 创建虚拟环境

```bash
python -m venv venv
# Windows
venv\Scripts\activate
# Linux/Mac
# source venv/bin/activate
```

#### 2.3 安装依赖

```bash
pip install -r requirements.txt
```

#### 2.4 配置环境变量

编辑 `.env` 文件，填写实际的API密钥：

```
# 数据库配置
DATABASE_URL=sqlite:///db.sqlite3

# 百度API配置
BAIDU_API_KEY=your_baidu_api_key
BAIDU_SECRET_KEY=your_baidu_secret_key

# GLM大模型API配置
GLM_API_KEY=your_glm_api_key

# Django配置
SECRET_KEY=your_django_secret_key
DEBUG=True
```

#### 2.5 数据库迁移

```bash
python manage.py migrate
```

#### 2.6 创建超级用户

```bash
python manage.py createsuperuser
```

#### 2.7 运行开发服务器

```bash
python manage.py runserver
```

访问 <http://localhost:8000> 查看系统

## 核心功能使用说明

### 1. 中药材资料管理

#### 浏览中药材
- 访问首页，点击"中药材"下拉菜单
- 选择"药材列表"查看所有中药材
- 点击药材名称查看详细信息

#### 搜索中药材
- 在首页搜索框输入关键词
- 点击搜索按钮或按回车键
- 查看搜索结果

### 2. 中药图像识别

#### 上传图片识别
- 访问"图像识别"页面
- 点击"选择文件"按钮上传图片
- 点击"开始识别"按钮
- 查看识别结果

### 3. 药材销售系统

#### 发布供应信息
- 登录系统
- 访问"药材销售"页面
- 点击"发布供应"按钮
- 填写供应信息表单
- 点击"提交"按钮

#### 管理个人发布的信息
- 登录系统
- 访问"个人中心"页面
- 在"我的供应信息"或"我的求购信息"部分管理发布的信息

### 4. 价格模块

#### 查看今日价格
- 访问"药材销售"页面
- 点击"价格查询"或类似链接
- 查看今日价格列表
- 使用分页和搜索功能

### 5. 大模型答疑

#### 提问
- 访问"大模型答疑"页面
- 在输入框中输入问题
- 点击"发送"按钮
- 查看AI回答

#### 多轮对话
- 在提问后，继续在输入框中输入后续问题
- 系统会基于上下文进行回答

## 系统管理

### 后台管理
- 超级用户登录后，点击导航栏中的"后台管理"链接
- 在后台管理界面中管理所有系统数据
- 包括用户、中药材、销售信息、新闻等

### 数据导入
- 销售数据支持Excel导入
- 价格数据支持自动爬取

## 常见问题

### 1. 图像识别失败
- 确保上传的图片清晰
- 确保图片中包含完整的中药材
- 尝试不同角度的图片

### 2. 价格数据未更新
- 检查网络连接
- 检查API配置
- 手动触发价格爬取

### 3. 无法登录
- 检查用户名和密码
- 检查网络连接
- 联系管理员重置密码
